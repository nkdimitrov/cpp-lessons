C++17 Strings - words, letters and text

Lesson 03 | Theory, cheat sheet and 12 practice problems from arena.olimpiici.com (Group D)

1. A string is a row of characters

A string holds text. Add #include <string> at the top. The characters have numbered places, and counting starts at 0:

string s = "hello";

//  place:      0    1    2    3    4
//  character: 'h'  'e'  'l'  'l'  'o'

cout << s[0] << '\n';        // h
cout << s.size() << '\n';    // 5
cout << s[s.size() - 1];     // o - the last character

cin >> s reads one word: everything up to the next space or new line.

To look at every character, loop over the places. Write int n = s.size(); first and use n in the loop:

string s;
cin >> s;
int n = s.size();
int vowels = 0;
for (int i = 0; i < n; i++) {
    if (s[i] == 'a' || s[i] == 'e' || s[i] == 'i' || s[i] == 'o' || s[i] == 'u') vowels++;
}
cout << vowels << '\n';

There is also a short form that hands you each character in turn, when you do not need its place: for (char c : s) { ... }.

2. Characters are numbers

Inside the computer every character is a small number, its ASCII code. The letters and the digits come in order:

Characters Codes
'0' ... '9'48 ... 57
'A' ... 'Z'65 ... 90
'a' ... 'z'97 ... 122

You never need to remember the codes. Because they are in order, subtracting the first one gives a small number you can use:

int d = '7' - '0';            // 7      digit character -> its value
int i = 'c' - 'a';            // 2      letter -> its place in the alphabet, from 0
char c = 'a' + 2;             // 'c'    place -> letter
char e = '0' + 7;             // '7'    value -> digit character

#include <cctype> gives ready-made tests and changes:

Call Gives
isdigit(c)true for '0' ... '9'
isalpha(c)true for a letter
isupper(c) / islower(c)true for a capital / a small letter
toupper(c) / tolower(c)the same letter as a capital / as a small letter

3. Walking along a string

A run is a block of equal characters side by side: "aaabbc" has three runs. Push j forward while the character stays the same, then jump i to j:

string s = "aaabbc";
int n = s.size();
int i = 0;
while (i < n) {
    int j = i;
    while (j < n && s[j] == s[i]) j++;
    cout << s[i] << ' ' << j - i << '\n';   // a 3, then b 2, then c 1
    i = j;
}

s.find(t) gives the place where t first appears inside s. When t is not there, it gives the special value string::npos:

string s = "banana";
if (s.find("nan") != string::npos) cout << "found\n";
cout << s.find('n') << '\n';    // 2

4. Changing and comparing strings

Call Does Example with `s = "hello"`

s + ta new string, s and t glueds + " you" is "hello you"
s.substr(p, len)a copy of len characters starting at place ps.substr(1, 3) is "ell"
reverse(s.begin(), s.end())turns s back to front (needs <algorithm>)"olleh"

The easiest way to remove characters is to build a new string from the ones you keep:

string s = "a-b-c", t = "";
for (char c : s)
    if (c != '-') t += c;
cout << t << '\n';          // abc

== and < compare strings like a dictionary: letter by letter from the left. "apple" < "apply" is true because 'e' comes before 'y'.

Every capital letter has a smaller code than every small letter, so "Zoo" < "apple" is true. Make the letters the same case before comparing words.

5. Reading a whole line

cin >> s stops at the first space. To read a line with spaces in it, use getline:

string line;
getline(cin, line);           // input: I like C++
cout << line.size() << '\n';  // 10
After cin >> n, the end of that line is still waiting. A getline right after it reads an empty line. Put cin.ignore(); between them.
int n;
cin >> n;
cin.ignore();                 // skip the end of the line with n
string line;
getline(cin, line);           // now this is the next line

6. Counting letters

Many string problems are solved by counting how often each letter appears. Make an array with one box per letter. c - 'a' tells you which box:

string s;
cin >> s;                         // small letters only
int cnt[26] = {0};                // 26 boxes, all 0
for (char c : s) cnt[c - 'a']++;

cout << cnt['e' - 'a'] << '\n';   // how many 'e'

int best = 0;                     // the most common letter
for (int i = 1; i < 26; i++)
    if (cnt[i] > cnt[best]) best = i;
cout << char('a' + best) << '\n';

Two words are anagrams (the same letters in another order) exactly when all 26 counts are equal.

7. Palindromes

A palindrome reads the same backwards: level, abba. Check it with two places, one coming from the left and one from the right:

bool is_pal(string s) {
    int n = s.size();
    int i = 0, j = n - 1;
    while (i < j) {
        if (s[i] != s[j]) return false;
        i++;
        j--;
    }
    return true;
}

The short way makes a reversed copy and compares:

string r = s;
reverse(r.begin(), r.end());
bool pal = (s == r);

One more rule worth knowing: the letters of a word can be rearranged into a palindrome exactly when at most one letter appears an odd number of times. All the others pair up around the middle.

9. 5 pitfalls that cost real marks

Places start at 0.In "hello" the last character is s[4], not s[5]. s[s.size()] is outside the string.
The second number of substr is a length, not an end place.s.substr(2, 3) is three characters starting at place 2.
getline right after cin >> n reads an empty line.The end of the line with n is still waiting. Put cin.ignore(); between them.
cnt[c - 'a'] with a capital letter or a digit.'A' - 'a' is negative and lands outside the array. Use tolower(c) first, or check islower(c).
Capitals come before all small letters."Zoo" < "apple" is true. Make the case the same before comparing or sorting words.
