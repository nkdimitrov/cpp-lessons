C++17 Vectors - a list that grows

Lesson 05 | Theory, cheat sheet and 12 practice problems from arena.olimpiici.com (Group D)

1. A list that grows

An array has a fixed size. A vector starts empty and grows each time you add something. Add #include <vector> at the top.

vector<int> v;           // empty
v.push_back(5);          // {5}
v.push_back(8);          // {5, 8}
v.push_back(1);          // {5, 8, 1}

cout << v.size() << '\n';    // 3
cout << v[0] << '\n';        // 5 - places start at 0, as in an array

This is exactly what you need when you do not know in advance how many values are coming. Read until a stop sign and keep everything:

vector<int> v;
int x;
while (cin >> x && x != 0)   // the input ends with 0
    v.push_back(x);

2. A vector of a given size

When you do know the size, make the vector that size at once. The size may come from the input:

int n;
cin >> n;
vector<int> a(n);            // n boxes, all 0
for (int i = 0; i < n; i++) cin >> a[i];

vector<int> c(n, -1);        // n boxes, all -1

From here on, a is used exactly like an array.

3. Walking through, the last element, sorting

int m = v.size();            // like strings: copy the size into an int first
for (int i = 0; i < m; i++) cout << v[i] << ' ';

cout << v.back();            // the last element
v.pop_back();                // remove the last element
v.clear();                   // remove everything

Sorting and reversing a whole vector need #include <algorithm>:

sort(v.begin(), v.end());        // smallest first
reverse(v.begin(), v.end());     // back to front

v.begin(), v.end() simply means "the whole vector". Lesson 08 is all about sorting.

4. Digits and numbers in a vector

Taking a number apart with % 10 gives its digits from the last one to the first. Put them in a vector and you can look at all of them as often as you like:

long long n = 4728;
vector<int> d;
while (n > 0) {
    d.push_back(n % 10);
    n /= 10;
}
// d is {8, 2, 7, 4} - the digits backwards

Change 10 to b and you get the digits in base b. To check whether the number is a palindrome in that base, compare d with a reversed copy of itself.

A vector is also handy for a list of special numbers that you make yourself, for example all Fibonacci numbers up to a limit:

vector<long long> f;
f.push_back(1);
f.push_back(2);
while (f[f.size() - 1] + f[f.size() - 2] <= 1000000000000LL)
    f.push_back(f[f.size() - 1] + f[f.size() - 2]);

5. Building a new vector

To throw some elements away, do not delete them one by one. Build a new vector with the ones you keep, then replace the old one:

vector<int> keep;
int m = v.size();
for (int i = 0; i < m; i++)
    if (v[i] % 2 == 0) keep.push_back(v[i]);     // keep the even ones
v = keep;

To put a value in the middle, use insert. Everything after it moves one place right:

vector<int> v = {10, 20, 30};
v.insert(v.begin() + 1, 15);     // {10, 15, 20, 30} - 15 goes to place 1
insert and erase in the middle move all the elements after that place. Doing that many times on a long vector is slow. Building a new vector is one pass.

6. One list for each group

An array of vectors gives every group its own list. Here every value gets the list of places where it appears:

vector<int> pos[1001];           // values are from 0 to 1000

int n;
cin >> n;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    pos[x].push_back(i);         // x was seen at place i
}
cout << pos[7].size() << '\n';   // how many times 7 appeared

The same idea stores a map of roads: nb[c] is the list of towns next to town c. A road between a and b adds b to nb[a] and a to nb[b].

8. 5 pitfalls that cost real marks

v[i] before anything is there.vector<int> v; v[0] = 5; writes outside the vector. Use push_back, or make the vector big enough first with vector<int> v(n);.
v.size() - 1 on an empty vector.size() cannot be negative, so 0 - 1 becomes a gigantic number. Copy it into an int first: int m = v.size();.
Erasing inside a loop over places.After an erase, the next element slides into the place you just looked at, and the loop skips it. Build a new vector instead.
Forgetting to clear between test cases.A vector keeps its old elements. If one input holds several tests, v.clear() before each.
The digits come out backwards.n % 10 gives the last digit first. Reverse the vector if you need them in the usual order.
