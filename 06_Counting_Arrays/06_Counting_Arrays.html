C++17 Counting arrays - one box per value

Lesson 06 | Theory, cheat sheet and 12 practice problems from arena.olimpiici.com (Group D)

1. One box per value

In lesson 04 the box number was a place in a row. Here the box number is the value itself. Box x counts how many times x has been seen:

int cnt[10];                     // outside main, so all 0

int main() {
    string s;                    // a long number, digit by digit
    cin >> s;
    for (char c : s) cnt[c - '0']++;

    for (int d = 0; d <= 9; d++)
        if (cnt[d] > 1) cout << d << " appears " << cnt[d] << " times\n";
}

One pass fills the boxes. After that, every question "how many times did x appear?" costs one look: cnt[x].

2. How many boxes?

You need one box for every value that can appear. If the values go from 0 to 1000, make 1001 boxes - the last one is box 1000:

int cnt[1001];                   // values 0 ... 1000
  • The values must be whole numbers and not too big. A million boxes is fine; a billion is not.
  • If values can be negative, shift them. For values from -500 to 500 use cnt[x + 500].
  • If values are huge (say up to 10^9) but there are few of them, a counting array will not fit. Lesson 11 shows map for that.

3. Marking: seen or not seen

Sometimes you only need to know whether a value appeared. A bool array is enough:

bool seen[1001];                 // all false

int distinct = 0;
for (int i = 0; i < n; i++) {
    if (!seen[a[i]]) distinct++;    // a new value
    seen[a[i]] = true;
}

Marking answers questions about other values in one step. Is there an earlier number that adds up with x to S? Look up S - x before marking x:

int pairs = 0;
for (int i = 0; i < n; i++) {
    int x = a[i];
    if (S - x >= 0 && S - x <= 1000 && seen[S - x]) pairs++;
    seen[x] = true;
}

And once the values are marked, walking along the boxes shows them in order. The longest run of marked boxes is the longest stretch of consecutive values.

4. The commonest value, and counting pairs

The value seen most often is the box with the biggest count:

int best = 0;
for (int v = 1; v <= 1000; v++)
    if (cnt[v] > cnt[best]) best = v;      // ties go to the smaller value

How many pairs of equal values are there? A box with c equal values gives c * (c - 1) / 2 pairs, because each of the c values pairs with each of the other c - 1, and that counts every pair twice:

long long pairs = 0;
for (int v = 0; v <= 1000; v++)
    pairs += 1LL * cnt[v] * (cnt[v] - 1) / 2;

5. Counting as you go

Fill the boxes while walking, and each box tells you how many times a value appeared *before* the current place. That counts pairs in a single pass:

long long pairs = 0;
for (int i = 0; i < n; i++) {
    pairs += cnt[a[i]];          // every earlier equal value makes a pair with a[i]
    cnt[a[i]]++;                 // now count a[i] itself
}

Walk from the right instead, with a second array, and you know how many equal values come *after* each place.

6. Printing in order from the boxes

Walk the boxes from the smallest value to the largest and print each value as many times as it was counted. The numbers come out sorted. This is called counting sort:

for (int v = 0; v <= 1000; v++)
    for (int k = 0; k < cnt[v]; k++)
        cout << v << ' ';

The same walk finds the k-th smallest value without storing the numbers at all: keep subtracting counts until k is used up.

int k;                           // the k-th smallest, counting from 1
cin >> k;
for (int v = 0; v <= 1000; v++) {
    if (k <= cnt[v]) { cout << v << '\n'; break; }
    k -= cnt[v];
}

8. 5 pitfalls that cost real marks

One box too few.Values up to 1000 need cnt[1001]. cnt[1000] has no box 1000.
Negative values as an index.cnt[-3] is outside the array. Shift every value by the same amount first.
A counting array for huge values.int cnt[1000000000]; does not fit in memory. Use a map (lesson 11) or sort the values.
Forgetting to reset between tests.Counts left over from the previous test give wrong answers. Set the boxes back to 0.
Pairs overflow.c * (c - 1) / 2 for c = 100000 is about 5 billion. Use long long.

9. Complexity reference

OperationCost
Filling the boxes for n valuesO(n)
Looking up cnt[x] or seen[x]O(1)
Walking all the boxesO(number of possible values)
Counting sortO(n + number of possible values)
