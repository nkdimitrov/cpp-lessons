C++17 Numbers - int, long long, bool and double

Lesson 02 | Theory, cheat sheet and 12 practice problems from arena.olimpiici.com (Group D)

1. int and long long

An int holds whole numbers from about -2 billion to +2 billion. The exact limits are -2147483648 and 2147483647.

When a result goes past that limit, it does not stop with an error. It quietly turns into a wrong number. This is called overflow.

int a = 100000;
int b = a * a;               // should be 10000000000
cout << b << '\n';           // prints 1410065408 - wrong!

A long long holds whole numbers up to about 9 000 000 000 000 000 000 - a 9 followed by 18 digits. Use it when the numbers can be big:

long long a = 100000;
long long b = a * a;         // 10000000000 - correct
The computer decides the type of a * a from a, not from where you put the answer. With int a, the line long long b = a * a; still overflows, because the multiplying happens in int first. Make the numbers themselves long long, or write 1LL * a * a.

A simple rule: if a number in the statement can be bigger than about a billion, or you multiply two big numbers together, use long long for everything.

2. Division and remainder

For whole numbers, / throws away the part after the point, and % gives what is left over:

cout << 17 / 5 << '\n';      // 3
cout << 17 % 5 << '\n';      // 2       because 17 = 3 * 5 + 2

Put the first two together in a loop and you can take any number apart, digit by digit:

int n = 4728, sum = 0;
while (n > 0) {
    sum += n % 10;           // add the last digit
    n /= 10;                 // and drop it
}
cout << sum << '\n';         // 4 + 7 + 2 + 8 = 21

The same two signs change units. 135 minutes is 135 / 60 = 2 hours and 135 % 60 = 15 minutes.

Rounding up: how many boxes of 6 do you need for 20 eggs? 20 / 6 is only 3. The trick is (a + b - 1) / b, so (20 + 5) / 6 = 4.

3. A formula instead of a loop

Some answers can be counted with a loop, but the loop would take far too long when the numbers are big. A formula gives the answer in one step.

Adding 1 to n. 1 + 2 + ... + n = n * (n + 1) / 2. For n = 100 that is 100 * 101 / 2 = 5050.

Counting multiples. From 1 to b there are b / c multiples of c. From a to b, take away the ones below a:

long long a, b, c;
cin >> a >> b >> c;
cout << b / c - (a - 1) / c << '\n';

Counting whole numbers between two others. Strictly between 3 and 8 lie 4, 5, 6 and 7: that is 8 - 3 - 1 = 4 numbers.

Always test a formula on a small example by hand. Multiples of 3 from 4 to 10 are 6 and 9. The formula gives 10 / 3 - 3 / 3 = 3 - 1 = 2. Correct.

4. true and false: bool

A bool holds one of two values: true or false. Every comparison gives a bool:

int n = 12;
bool even = (n % 2 == 0);        // true
if (even) cout << "even\n";
Sign Means Example
&&and - both must be truex >= 1 && x <= 10
||or - at least one must be truec == 'a' || c == 'e'
!not!even
= puts a value into a variable; == compares. if (x = 5) sets x to 5 and is always true. It compiles, so the compiler will not save you.

5. Decimal numbers and square roots

A double holds numbers with a decimal point, such as 3.75. If both numbers in a division are whole, the answer is whole too. Make one of them a double to keep the part after the point:

cout << 7 / 2 << '\n';        // 3
cout << 7.0 / 2 << '\n';      // 3.5

To print exactly two digits after the point, add #include <iomanip> and write:

double x = 2.0 / 3;
cout << fixed << setprecision(2) << x << '\n';      // 0.67

sqrt(x) from <cmath> gives the square root. But a double is not always exact: sqrt(49) may come out as 6.9999999, and turning that into an int gives 6. So when you need a whole square root, correct it with whole numbers:

long long n = 49;
long long r = sqrt(n);
while (r * r > n) r--;                 // r was one too big
while ((r + 1) * (r + 1) <= n) r++;    // r was one too small
if (r * r == n) cout << "perfect square\n";
Use double only when the problem really has decimals. Whole numbers are always exact; decimals are not - even 0.1 + 0.2 is not exactly 0.3.

7. 5 pitfalls that cost real marks

An int that overflows gives a wrong number and no warning.If the answer can pass two billion, use long long - for the answer and for the numbers that make it.
long long x = a * b; with int a, b still overflows.The multiplication happens in int first. Write 1LL * a * b or make a and b long long.
7 / 2 is 3, not 3.5.Whole numbers divide to a whole number. Write 7.0 / 2 when you want the decimals.
= instead of == inside an if.if (x = 0) changes x and is never true. Compare with ==.
Trusting sqrt to be exact.(int)sqrt(49) can be 6. Correct the root with whole numbers before you use it.
